BMH INVENTARIO — CONFIGURACIÓN DE SUPABASE

PROYECTO
URL: https://TU-PROYECTO.supabase.co
Clave publicable: usa la clave sb_publishable que tienes. Esta clave está diseñada para el cliente, pero solo es segura junto con las políticas RLS. No compartas claves sb_secret, service_role ni contraseña de PostgreSQL.

PASO A: CREAR TABLAS Y POLÍTICAS
1. Entra al Dashboard de Supabase y abre el proyecto que tenga la URL anterior.
2. En el menú, abre SQL Editor.
3. Pulsa New query.
4. Abre el archivo supabase/migrations/001_initial_schema.sql de este paquete.
5. Copia TODO el contenido y pégalo en SQL Editor.
6. Pulsa Run. Si aparece un error, no sigas al siguiente paso: copia el mensaje exacto del error y corrígelo primero.
7. En Table Editor deben aparecer profiles, businesses, business_members, warehouses, products e inventory_movements.
8. En Authentication > Providers > Email, revisa si la confirmación por correo está habilitada.

PASO B: PREPARAR URL DE AUTENTICACIÓN
1. En Authentication > URL Configuration, configura Site URL como http://localhost:5173 para desarrollo local.
2. Si hay Redirect URLs, agrega http://localhost:5173/**.
3. Antes de publicar, cambia la URL al dominio HTTPS definitivo y agrega ese dominio a Redirect URLs.

PASO C: CONECTAR LA WEB
1. En la carpeta del proyecto, duplica .env.local.example y nombra la copia .env.local.
2. Deja VITE_SUPABASE_URL=https://yuvjcmksynyukkrnheyn.supabase.co.
3. Sustituye el texto de VITE_SUPABASE_PUBLISHABLE_KEY por la clave sb_publishable que compartiste.
4. No añadas ninguna clave sb_secret ni service_role al archivo .env.local del frontend.
5. Ejecuta npm install y luego npm run dev.
6. Abre http://localhost:5173, crea cuenta y después crea el negocio y almacén.

Si npm no se reconoce en PowerShell, instala Node.js LTS desde https://nodejs.org, cierra y vuelve a abrir PowerShell y comprueba `node -v` y `npm -v`.

IMPORTANTE: no ejecutes esta migración en un proyecto que ya tenga tablas con estos mismos nombres y datos valiosos sin revisar primero el esquema existente y hacer un respaldo.
