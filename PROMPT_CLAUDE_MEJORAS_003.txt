PROMPT PARA CLAUDE — CONTINUAR BMH INVENTARIO SIN REHACERLO

Actúa como desarrollador senior full-stack especializado en React + TypeScript + Supabase/PostgreSQL y seguridad RLS. Estoy trabajando sobre un proyecto existente llamado BMH Inventario. NO lo rehagas desde cero ni borres funciones existentes. Primero inspecciona todos los archivos, entiende las tablas y funciones existentes y luego implementa cambios compatibles.

OBJETIVO
Entregar una aplicación de inventario usable y lista para desplegar, manteniendo React/Vite/TypeScript y Supabase. Debe funcionar con las migraciones 001_initial_schema.sql, 002_warehouse_join_usernames.sql y 003_sku_barcode_categories_permissions.sql, en ese orden. No pidas ni uses service_role/secret keys en frontend; únicamente VITE_SUPABASE_URL y VITE_SUPABASE_PUBLISHABLE_KEY.

CAMBIOS YA PREPARADOS EN EL PROYECTO
- Migración 003 agrega secuencias para SKU y código de barras, tabla de categorías por almacén, columnas de permisos granulares, función set_member_permissions, trigger de SKU/código de barras, y refuerza que solo businesses.created_by administre permisos.
- La interfaz tiene selector de modo oscuro y una sección Opciones con alta de categorías persistidas.

8. Opciones adicionales útiles: perfil editable, copiar código de almacén, filtros por categoría/stock bajo, exportación CSV, confirmación antes de acciones destructivas, estados de carga/error, accesibilidad y diseño móvil. No agregar funciones vacías ni botones decorativos.
